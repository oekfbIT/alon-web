| `ai.md` | All AI work in one place: shipped, in progress, planned, how I use AI tools |
| `skills.md` | Stack by area, with strength levels |
| `education-languages.md` | Education and languages |
| `references.md` | What former employers wrote (translated) |
| `ways-of-working.md` | How I work, engineering principles, lessons learned |
| `interview/answered.md` | Interview questions I can already answer from the files above, with draft answers |
| `interview/to-review.md` | Questions where I'm weak or the facts are missing: to answer myself |
