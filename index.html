How the chat on this page works

  1. Your question
  2. BM25 retrieval over my knowledge base
  3. Top passages as context
  4. Model answers only from them
  5. Answer with sources

The knowledge base is written from this site, so the chat can’t claim anything the site doesn’t. Without a model configured, it answers directly from the best-matching passages. Same idea as my federation AI previews: compute or retrieve the facts first, let the model only phrase them.

For AI engineering in depth, see the AI match previews, vision matching at THATSIT! and the match analysis I’m building now.
