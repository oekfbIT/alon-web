Generated Kit Images

Turns an uploaded jersey into a standardised home or away kit illustration, validates the transparent PNG and shows a preview before it is saved.

Read the technical deep diveAbout my role at ÖKFB

Overview

Every club uploads its own jersey, and every upload looks different: other angles, backgrounds and sizes. To show kits uniformly in the app and on the website, this feature takes over the club’s own design and turns it into a standardised home or away kit illustration.

Admins upload the jersey in the dashboard, check a preview of the generated kit and only then save it.

How it works

  1. Upload. An admin uploads a club’s jersey in the dashboard.
  2. Generate. The jersey and a layout reference go into the image generation as inputs, and the kit illustration comes back.
  3. Validate. The transparent PNG is checked: structure, CRCs, visible pixels and transparent edges.
  4. Preview. The admin sees the result before anything is saved.
  5. Save. The kit is stored in Firebase Storage, and stale saves are rejected.

What I built

  • Reference-guided image generation that keeps the club’s own jersey design.
  • PNG validation before anything is stored, so broken images never reach the app or website.
  • Preview step in the React admin dashboard, with storage in Firebase and protection against stale saves.
  • Swift/Vapor backend endpoints behind the dashboard.
