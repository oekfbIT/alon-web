AI Match Previews & Reviews

German match previews and matchday reviews on oekfb.eu. The backend computes the football facts; the model only chooses which verified facts to use, and the backend writes the article.

Read the technical deep diveAbout my role at ÖKFB

Overview

Every week the federation used to publish a weekly report (Wochenbericht) covering all games played. Writing it by hand took two to three days, and there was no head-to-head information for upcoming matches.

Now previews before every match and a review of each matchday are generated in German on oekfb.eu. They bring players and teams back to the site with what they care about: table placements, top scorers, head-to-head records and the key games of the round.

Football fans notice a wrong number immediately, so the model never invents facts. The backend computes them, the model only chooses which verified facts to use, and the backend writes the article.

How it works

  1. Compute. The backend calculates form, table position, head-to-head, scorers, discipline and confirmed absences, with a historical cutoff so a preview never uses results from after the match.
  2. Choose. Through strict JSON Schema outputs, the model selects and orders verified facts and title candidates.
  3. Write. The backend renders the article from those choices instead of publishing free text.
  4. Review. Admins review, edit, publish or delete each article.
  5. Publish. Previews go live before each match and a matchday review follows on oekfb.eu.

What I built

  • Replaced a 2–3 day manual weekly report with automatic generation.
  • Computed football facts: form, table position, head-to-head, top scorers, discipline and absences.
  • Strict JSON Schema outputs so the model selects facts and the backend writes the text.
  • Persistent background jobs with bounded concurrency, retries with backoff and idempotency keys.
  • Every article records its source snapshot, model, prompt version, selected facts and token usage.
  • Provider-independent: an OpenAI-compatible adapter behind an interface.
